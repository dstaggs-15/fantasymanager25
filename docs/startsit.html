Start / Sit Comparator

How it works: we blend **usage**, **efficiency**, **offensive line**, **opponent difficulty**, **game environment**, and **consistency**. Scores are 0–100; higher is better. Component bars show contribution (0–100%).

What the components mean

  • Usage: snaps/attempts/targets/air yards & red‑zone usage (last 5 games).
  • Efficiency: position‑specific (e.g., RB yards before/after contact, YPRR for WR/TE, EPA for QB) if available.
  • O‑line: optional 0–1 team grade (neutral if missing).
  • Opponent: defense vs position (recent points allowed; lower allowed = tougher).
  • Environment: optional Vegas implied team points (neutral if missing).
  • Consistency: steadiness (lower stdev/mean → higher consistency).
