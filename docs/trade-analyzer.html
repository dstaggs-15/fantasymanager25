Trade Analyzer

How This Tool Works

Add players to each side of the trade to get a data-driven analysis. The tool evaluates the trade based on two key areas:

  • Season-Long Value: Calculated using each player's VORP (Value Over Replacement Player).
  • Immediate Impact: Calculated using each player's weekly Start Score.

A final Trade Grade combines these factors to give you a holistic view of the deal.
