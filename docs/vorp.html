VORP & Player Analysis

How to Use This Tool

VORP (Value Over Replacement Player) measures a player's true value by comparing them to a "replacement-level" player (the best player likely available on the waiver wire). A higher VORP means a bigger weekly advantage.

  1. Set Replacement Levels: Use the input boxes to define the rank of the replacement player for each position. For a 10-team league, defaults are QB11, RB22, WR32, and TE11.
  2. Compare Players: Use the search bars to select any two players for a side-by-side comparison of their stats.
  3. Analyze Rankings: The main table ranks all players by their VORP, based on the levels you set.
